The Julia Manifest in the release holds two complete manifests; scripts/setup_julia.sh splits it into the QXTools/CUDA.jl environment and the XGBoost.jl environment. The xgboost pin matters: 3.4.1 trains measurably different models from the same inputs, so the project stays on 2.1.4, the release closest to the authors' XGBoost_jll 2.1.5. CuPy's ctk extra supplies the CUDA headers this machine lacks; its bundled CUDA 12.9 runtime works on driver 535 through minor-version compatibility. The only GPU evidence so far is tests/test_setup.py::test_cupy_runs_on_gpu, a 64×64 einsum. Present it as setup, not as a result.
